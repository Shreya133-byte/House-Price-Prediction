# 🏠 House Price Prediction

An end-to-end Machine Learning project for predicting house sale prices using the Ames Housing dataset.

The project demonstrates the complete regression workflow, including exploratory data analysis, data cleaning, feature engineering, preprocessing, model comparison, hyperparameter tuning, error analysis, and an interactive Gradio prediction interface.

Demo link : https://182deb9ada9cadacb5.gradio.live/
---

## 🎯 Project Objective

The objective of this project is to develop a machine learning system capable of estimating house prices based on various property characteristics.

The project focuses on building a complete and reproducible machine learning pipeline rather than simply training a single regression model.

---

## 📊 Dataset

The project uses the **Ames Housing / House Prices dataset**.

The dataset contains information about residential properties, including:

- Overall quality
- Living area
- Basement area
- Garage capacity
- Year built
- Number of bathrooms
- Neighborhood
- Various structural and property characteristics
